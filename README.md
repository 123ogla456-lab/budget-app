# Мини-апп «Бюджет»

Телеграм-мини-апп: интерфейс бюджета на месяц.
Открывается кнопкой «Бюджет» в боте `@my_finance20206bot`.

- `index.html` — вся вёрстка и логика, один файл
- `data.json` — данные, которые он читает

Живёт на GitHub Pages: https://123ogla456-lab.github.io/budget-app/
Деплой автоматический — что запушено в `main`, то через минуту в эфире.

## Важно про данные

**Репозиторий публичный, и `data.json` доступен по прямой ссылке кому угодно.**
GitHub Pages на бесплатном тарифе иначе не работает.

Сейчас в `data.json` лежат демонстрационные цифры, полученные вместе с макетом, —
это не настоящие финансы Ольги. Реальные доходы и расходы в этот файл класть нельзя,
пока хостинг публичный.

Варианты, если понадобятся настоящие данные:
- перенести на свой домен с TLS и закрыть проверкой подписи Telegram `initData`;
- приватные GitHub Pages (нужен платный тариф).
