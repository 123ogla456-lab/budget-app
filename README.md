# Мини-апп «Бюджет»

Телеграм-мини-апп: бюджет на месяц, доходы и расходы по категориям.
Открывается кнопкой «Бюджет» в боте `@my_finance20206bot`.

- `index.html` — вся вёрстка и логика, один файл
- `data.json` — пустая заготовка: категории и нулевой план

Живёт на GitHub Pages: https://123ogla456-lab.github.io/budget-app/
Деплой автоматический: что запушено в `main`, то через минуту-две в эфире.

## Где лежат данные

**На устройстве, в `localStorage` браузера.** Всё, что вносится в приложении —
операции, категории, планы, — сохраняется локально и на сервер не уходит.

Так сделано намеренно: репозиторий публичный (иначе GitHub Pages на бесплатном
тарифе не работает), и любой файл на нём открыт по прямой ссылке. Реальные цифры
в `data.json` класть нельзя.

Что из этого следует:
- на другом телефоне будет пусто — данные не синхронизируются;
- очистка данных сайта в браузере сотрёт учёт;
- Финансист (бот) этих цифр не видит, у него свой журнал.

Полный сброс — в «Плане на месяц», кнопка «Стереть все данные».

## Если понадобится общий доступ с нескольких устройств

Нужен свой домен с TLS и проверка подписи Telegram `initData` на сервере —
тогда данные можно хранить у себя и отдавать только Ольге.
Либо платный тариф GitHub с приватными Pages.
